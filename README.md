# 内存释放任务栏工具

面向 Windows 11 x64 的本地内存状态与清理工具，可显示内存和网络状态，手动或定时整理后台进程工作集，并按明确配置关闭指定后台组件。

## 当前版本

- 版本：`3.15.3`
- 系统：Windows 11 x64
- 一键安装包：`dist/MemoryCleanerFloat-Setup-v3.15.3.exe`
- 安装包校验值：`dist/MemoryCleanerFloat-Setup-v3.15.3-SHA256.txt`

## 主要功能

- 显示内存使用状态和网络速度。
- 左键执行一次内存清理，支持设置定时清理间隔。
- 可作为任务栏嵌入组件或悬浮窗口使用。
- 支持拖动位置、背景颜色、透明度和自定义外观。
- 通过 `KeepProcessNames` 保护指定进程，只关闭 `CloseProcessNames` 中明确列出的候选进程。
- 提供日志、清理预览和诊断脚本，便于排查任务栏模块及内存清理问题。

## 安装方法

1. 下载 `dist/MemoryCleanerFloat-Setup-v3.15.3.exe`。
2. 双击安装包并选择安装位置。
3. 保持“创建桌面快捷方式”勾选，点击“立即安装”。
4. 安装器会部署主程序、Windhawk Portable 和任务栏模块，并启动工具。
5. 首次解析当前 Windows 版本的系统符号可能需要联网并等待几分钟。

不需要开发环境、Git 或 PowerShell 7。安装器会优先复用已存在的 Portable Windhawk；没有时才部署到当前用户的本地应用数据目录。

## 基本操作

- 左键短按：执行一次内存清理。
- 右键：打开设置和完整菜单。
- 按住左键横向拖动：调整任务栏中的位置。
- 从悬浮窗口拖入任务栏：切换到任务栏嵌入模式。
- 托盘闪电图标：打开设置、日志、诊断或退出。

## 数据与隐私

- 设置保存在程序目录的 `settings.json`。
- 运行日志保存在 `cleaner.log`，维护状态保存在 `cleaner.state.json`。
- 工具读取本机内存、当前会话进程、任务栏状态和网络流量计数。
- 项目不会上传运行日志、状态文件、个人设置或历史构建缓存。

## 更新与卸载

更新时先退出旧版，再运行新版安装器并选择原安装目录；安装器会保留已有 `settings.json`。卸载可通过 Windows“设置 → 应用 → 已安装的应用”完成。

完整操作方法、限制和故障排查见 [使用说明.md](使用说明.md)。
